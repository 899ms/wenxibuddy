配置说明与常见问题

一、如何获取 API Key

服务商 API 地址 获取 Key 推荐模型
DeepSeek https://api.deepseek.com platform.deepseek.com → API Keys deepseek-chat / deepseek-reasoner
智谱 GLM https://open.bigmodel.cn/api/paas/v4 open.bigmodel.cn → API Keys glm-4-flash
SiliconFlow https://api.siliconflow.cn cloud.siliconflow.cn → API密钥 deepseek-ai/DeepSeek-V3
Ollama 本地 http://localhost:11434 无需 Key（留空即可） qwen3:4b / llama3

二、连接不上的排查步骤

  1. 确认地址正确：API 地址不要带 /v1 后缀（如写 https://api.deepseek.com 而非 https://api.deepseek.com/v1），系统会自动拼接。
  2. 确认 Key 有效：在服务商后台检查 API Key 是否已创建且未过期。DeepSeek 需先充值才能调用。
  3. 点击「测试连接」：会尝试拉取模型列表验证连通性。
  4. CORS 问题：如果页面是通过 file:// 协议打开的（地址栏以 file:// 开头），浏览器可能阻止跨域请求。解决方法：用本地 HTTP 服务打开。
    终端执行： cd ~/Desktop && python3 -m http.server 8080
    然后浏览器访问 http://localhost:8080/升级版04.html
