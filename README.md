WenXiBuddy

WenXiBuddy 是一款面向机关、事业单位及综合行政办公场景的本地化项目与事务管理工具。

项目采用单文件 HTML 形式交付，将任务管理、会议通知、文件收发、外出活动、用章登记、物资管理、工作统计和材料生成集中在一个页面中。无需安装数据库或部署后端服务，下载后即可在浏览器中运行。

当前主程序：WenXiBuddy0722.html

项目特色

一体化办公台账

文件收发

物资收发

工作统计

周报生成

公文一键排版

专项工作汇报

任务全过程管理

任务模块支持记录：

任务名称、类型和来源

交办时间与截止日期

交办人、配合单位或人员

未启动、进行中、已完成、已超期等状态

多阶段任务及不同阶段的协作人员

工作小结和产出资料

Word、Excel、PDF、图片等附件

系统能够根据截止日期自动计算剩余时间、识别超期任务，并支持筛选、搜索、分类、进度查看和任务续办。

多类行政事务管理

除任务外，系统还提供多个独立业务模块：

会议管理：记录会议主题、时间、地点、发送对象、接收方及附件。

文件收发：管理收文、发文、文件编号、密级、公文文种、经办人和回执状态。

外出活动：登记调研、会议、慰问、来访等活动及参与人员、成果和照片。

用章管理：记录用章时间、用章人、审批人、文件名称及文件类型。

物资管理：记录物资入库、领用、数量、经手人和来源单位，并统计库存变化。

AI 辅助材料生成

系统支持接入兼容 OpenAI 接口规范的大模型服务，可用于：

自动汇总指定时间范围内的工作记录

生成周报初稿

润色全文或选中文字

根据任务信息生成专项工作汇报

按正式公文风格整理材料

导出 Word 文档

撤销或恢复润色结果

可配置 DeepSeek、智谱 GLM、SiliconFlow、Ollama 等服务，并支持保存和切换多组模型配置。

本地优先的数据存储

WenXiBuddy 默认将数据保存在当前浏览器中：

结构化业务数据保存在 localStorage

附件和模型配置保存在 IndexedDB

可选用浏览器目录授权，将附件同步保存到本地文件夹

支持将全部业务数据和附件导出为 JSON

支持合并导入与覆盖导入

项目默认不需要远程数据库，适合个人办公、原型验证和对本地数据保存有要求的使用场景。

数据通常与浏览器及访问地址绑定。更换浏览器、设备或访问地址前，请先使用“数据迁移”功能导出备份。

附件管理与预览

系统支持拖拽或点击上传附件，并提供多种文件预览能力：

图片画廊及左右切换

PDF 预览

TXT 文本预览

DOCX 文档预览

DOC、WPS 等旧版文档的文本提取

XLS、XLSX、ET 表格预览

附件下载、删除与分类查看

单个附件建议控制在 20MB 以内。

可调整的三栏工作台

界面采用三栏式布局：

左侧：功能导航

中间：列表和工作区

右侧：详情面板

左右栏均可拖动调整宽度，也可以折叠。系统还提供浅色、深色主题和玻璃质感界面，使较复杂的事务信息仍能保持清晰的视觉层级。

快速开始

方法一：直接打开

下载 升级版04.html。

使用 Chrome、Edge 等现代浏览器打开。

新建任务或其他业务记录即可开始使用。

方法二：通过本地服务运行

如果需要使用大模型接口，推荐通过本地 HTTP 服务打开页面，避免 file:// 模式可能产生的跨域限制。

python3 -m http.server 8080

然后访问：

http://localhost:8080/升级版04.html

大模型配置

进入系统后，打开“大模型连接配置”，填写：

配置名称

API 地址

API Key

模型名称

系统会自动请求兼容接口：

GET  /v1/models
POST /v1/chat/completions

配置完成后，可以先使用“测试连接”确认模型是否可用。

API Key 保存在浏览器本地，但使用 AI 润色或材料生成功能时，相关文本会发送给你配置的模型服务商。请根据所在单位的数据管理要求谨慎处理敏感内容。

数据备份与迁移

系统提供两种导入方式：

合并模式：保留当前数据，根据记录 ID 去重后追加导入。

覆盖模式：清空当前浏览器中的数据，再写入备份内容。

建议在升级程序、更换设备、清理浏览器数据或切换访问地址之前，先导出完整 JSON 备份。

使用提示

建议定期导出 JSON 备份。

不同浏览器和不同访问地址的数据空间可能互不相通。

清理浏览器网站数据可能同时删除业务记录、附件和模型配置。

部分文件预览和导出组件通过 CDN 加载，使用相关功能时需要网络连接。

本项目目前以单机、本地使用为主，尚未提供账号体系、多人实时协作和云端同步。

处理涉密或敏感数据前，请确认符合所在单位的信息安全制度。
