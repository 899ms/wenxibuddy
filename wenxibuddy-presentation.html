概览

WenXiBuddy 是什么？

面向机关单位的一站式办公管理工具，将任务管理、会议管理、文件收发、外出活动、用章管理、物资收发、工作统计、周报生成八类高频业务集成于一个网页。

  • 单文件 HTML，无需安装，浏览器即用
  • visionOS 玻璃质感设计语言
  • 本地 IndexedDB + localStorage 持久化
  • 接入大模型 AI 辅助周报撰写

任务管理 — 全生命周期管控

  • 状态流转：未启动 → 进行中 → 已完成 / 已超期
  • 阶段化管理：支持任务拆分多个阶段，逐阶段推进
  • 多维筛选：状态 / 交办人 / 关键词 / 类目标签
  • 完成确认：记录产出资料，上传附件归档
  • 智能导入：支持粘贴文本批量导入任务
  • 类目体系：自定义一级/二级类目 + 颜色标记

任务筛选 — 精准定位

筛选维度

  • 状态筛选：全部 / 未启动 / 进行中 / 已完成 / 超期
  • 交办人筛选：动态读取已配置交办人列表
  • 关键词搜索：实时过滤任务名称与内容
  • 类目筛选：按自定义一级/二级类目分类查看
  • 标签筛选：支持多标签组合过滤

类目管理

  • 类目标签在任务卡片上可视化展示
  • 支持类目增删改查，即时生效
  • 会话级记忆当前选中类目
